# New Realm

**Hybrid Virtual Instrument** built with [HISE](https://hise.audio)

## Overview

New Realm is a VST3 synthesizer that blends attack and sustain layers from acoustic instruments, enabling unique hybrid timbres.

### Instruments

| Attack Layer | Sustain Layer |
|-------------|---------------|
| Piano | Piano |
| Guitar | Guitar |
| Vibraphone | Vibraphone |
| Marimba | Marimba |
| Glockenspiel | Glockenspiel |

Mix any attack with any sustain to create your signature sound.

## Features

- **Layer Blending** — Independent attack/sustain selection
- **Gain Control** — Per-layer volume adjustment
- **Transposition** — Pitch shifting capabilities
- **Zoom Interface** — Scalable UI (900x600 base)

## Structure

```
├── Scripts/          # HiseScript modules
├── Samples/          # Audio samples (.ch1)
├── SampleMaps/       # Sample mapping configs
├── Images/           # UI assets
└── XmlPresetBackups/ # Preset storage
```

## Requirements

- HISE 4.x+
- VST3-compatible DAW
